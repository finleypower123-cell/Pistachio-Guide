# Third-party notices

Pistachio Guide reuses code from these MIT-licensed projects. Their licence text is reproduced below.

| Project | What we use | Where |
| --- | --- | --- |
| [mapcn](https://github.com/AnmolSaini16/mapcn) | MapLibre React components (Map, markers, controls, GeoJSON layers) | `src/components/map/map.tsx` (worker served locally, OpenFreeMap basemaps) |
| [nextjs-supabase-shadcn-boilerplate](https://github.com/Barty-Bart/nextjs-supabase-shadcn-boilerplate) | Supabase browser client and session-refresh middleware pattern | `src/lib/supabase/*`, `src/middleware.ts` |
| [TRIP](https://github.com/itskovacs/TRIP) | OpenStreetMap tag → category mapping, ported from Python to TypeScript | `src/lib/osm.ts` |
| [nextjs-maplibre-starter](https://github.com/wellywahyudi/nextjs-maplibre-starter) | Reference for free OpenFreeMap tile styles and geolocation flow (no code copied verbatim) | `src/components/map/discovery-map.tsx` |

Data and services: map data © OpenStreetMap contributors (ODbL), Overpass API, Nominatim, OpenFreeMap tiles, Open-Meteo weather.
